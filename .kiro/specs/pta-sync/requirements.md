# PTA 数据同步 - 需求文档

## 背景
教师需要将 PTA（程序设计类实验辅助教学平台）上的班级实验数据同步到本系统中，用于后续的 AI 分析、成绩管理等功能。

## 用户故事

### US-1: 教师绑定 PTA 关键词
作为教师，我希望在班级管理中为每个班级设置 PTA 搜索关键词（如"计科23数据结构"），以便系统知道去 PTA 上爬取哪些题目集的数据。

### US-2: 教师控制同步开关
作为教师，我希望能开启/关闭某个班级的 PTA 数据同步，这样历史班级不会被无意义地重复爬取。

### US-3: 手动触发同步
作为教师，我希望能手动点击"立即同步"按钮，触发一次该班级的 PTA 数据爬取，而不必等定时任务。

### US-4: 查看同步状态
作为教师，我希望能看到每个班级的同步状态（上次同步时间、是否正在同步、同步结果），了解数据是否最新。

### US-5: 定时自动同步
作为系统，我需要定时（如每24小时）自动对所有开启同步的班级执行增量爬取。

## 核心约束
- PTA 账号密码由系统管理员统一配置（.env），不需要每个教师单独配置
- 爬虫服务（Python/FastAPI）独立部署，Java 后端通过 HTTP 调用
- 爬取采用增量模式，只爬新增的题目集
- 爬取结果先存文件，后续入库逻辑单独迭代

## 防爬虫频率保护（重要）
为避免对 PTA 服务器造成压力，需要在多个层面做限制：

### 前端层
- 手动"立即同步"按钮点击后进入冷却状态（灰色不可点），显示倒计时
- 冷却时间：同一班级 10 分钟内不可重复触发

### Java 后端层
- 同一班级的手动触发请求，检查 `last_sync_at`，10 分钟内拒绝重复请求
- 定时任务串行执行，班级之间间隔 5 分钟

### FastAPI 服务层
- 全局任务队列，同一时间只允许 1 个爬取任务运行，其他排队等待
- 如果队列已满（超过 5 个待执行），拒绝新任务
- 相同 keyword 的任务去重（队列中已有相同 keyword 则不重复入队）

### spider.py 爬取层（已有，需加强）
- API 请求间隔：每次请求后 random.uniform(1, 3) 秒延迟
- 导出请求间隔：每次导出后 random.uniform(3, 5) 秒延迟（导出是重操作）
- 全局限流：令牌桶算法，每分钟最多 20 次 API 请求
- 遇到 429 (Too Many Requests) 自动退避：等待 30 秒后重试，最多 3 次

## 不在本期范围
- 数据入库（写入新数据库表）
- AI 分析（代码分析、推荐题目等）
- 解压 zip / 解析 HTML 提取代码
- 查重功能
